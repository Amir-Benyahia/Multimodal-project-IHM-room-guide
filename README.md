# Salle IHM – Room Guide

Application de réalité augmentée (Unity, iOS et Android) qui reconnaît le vidéoprojecteur de la salle 111 et répond aux questions posées à la voix.

## Scripts (`Assets/Scripts`)

- `Detection` : reconnaissance du projecteur (IA) et QR codes
- `Dialogue` : micro, compréhension des questions, réponse vocale
- `InterfaceAR` : interface 3D, guide pas à pas, repères sur le mur
- `Donnees` : lecture de `Assets/Ressources/equipements.json`
- `Affichage` : interface 2D
- `Tests` : mode test sans projecteur
